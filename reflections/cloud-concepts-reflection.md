# Cloud Concepts Reflection

Before taking this subject, I didn't really know what cloud computing was. I was already using many online apps every day, but I never thought about how they actually worked. After learning about cloud computing, I realized that many of the apps I use depend on the cloud to store data and provide services anytime and anywhere as long as there is an internet connection.

One of the cloud services I use almost every day is **Google Drive**. It is a **Software as a Service (SaaS)** because I only use it to store and access my files online without worrying about how it is managed. It uses the **Public Cloud** because anyone with a Google account can use it through the internet.

Another app I always use is **Messenger**. It is also a **SaaS** because it lets me send messages, make calls, and share photos without installing or managing any servers. It is part of the **Public Cloud** since it is available to anyone who creates an account.

I also use **Canva**, especially when making school projects and presentations. Canva is another example of **SaaS** because everything I need is available online. It also uses the **Public Cloud** because it can be accessed by users around the world.

Learning about Git and GitHub helped me understand why version control is important. GitHub keeps track of changes, making it easier to work with others and avoid mistakes. It also lets you go back to previous versions if something goes wrong. Overall, I realized how useful GitHub is when working on projects.
