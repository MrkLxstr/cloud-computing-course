## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers the broadest range of services among the three providers. AWS currently provides more than 200 services across areas such as computing, storage, databases, networking, analytics, security, and application development.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. It is a natural choice for organizations that already use technologies such as Windows Server, Microsoft 365, and Microsoft identity services.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for Artificial Intelligence and Kubernetes workloads. Google Cloud provides AI-focused infrastructure and Google Kubernetes Engine (GKE), a managed Kubernetes service.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Google Cloud because I am interested in Artificial Intelligence, Machine Learning, and modern application development. Google Cloud also provides strong Kubernetes support through Google Kubernetes Engine. However, the best cloud platform can change depending on the organization's requirements, existing technology, budget, and technical skills.
