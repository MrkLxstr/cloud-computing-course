# Client Recommendations

## Client A – Startup Company

### Recommended Platform: AWS

AWS is a good choice for the startup because it provides a very large selection of cloud services that can support a mobile application as it grows. The startup can begin with relatively small resources and increase them as the number of users increases. AWS also provides services for application hosting, databases, storage, and monitoring. This allows the company to build its application without purchasing and maintaining a large physical infrastructure.

### Recommended Services

* Amazon EC2 – application computing
* Amazon S3 – object and file storage
* Amazon RDS – managed relational database
* Amazon CloudFront – content delivery

---

## Client B – University

### Recommended Platform: Microsoft Azure

Azure is the most appropriate choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's ecosystem and supports Windows-based workloads. The university can also use Microsoft identity services and Azure management tools when migrating existing systems. This can make the transition easier because the organization can continue using technologies that its staff already understand.

### Recommended Services

* Azure Virtual Machines – Windows Server workloads
* Microsoft Entra ID – identity and access management
* Azure Virtual Network – private cloud networking
* Azure SQL Database – managed SQL database

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud

Google Cloud is a strong choice for the AI research company because it provides infrastructure and services designed for Artificial Intelligence and Machine Learning workloads. Google Cloud also provides high-performance computing options and specialized AI infrastructure. Its data and ML services can support research, model development, training, and deployment. Google Kubernetes Engine can also be used when the company needs containerized ML workloads.

### Recommended Services

* Compute Engine – high-performance virtual machines
* Google Kubernetes Engine (GKE) – managed Kubernetes
* Vertex AI – AI and Machine Learning platform
* Cloud Storage – storage for datasets and model files

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is a strong choice for the global e-commerce company because it provides a large global infrastructure and services for scalable, highly available applications. The company can distribute workloads across multiple Availability Zones and Regions when appropriate. AWS also provides load balancing and automatic scaling capabilities that can help the application handle changes in traffic. This is useful for an online shopping platform that may experience large changes in demand.

### Recommended Services

* Amazon EC2 – application servers
* Elastic Load Balancing – distributes incoming traffic
* EC2 Auto Scaling – automatically adjusts compute capacity
* Amazon RDS – managed relational database
* Amazon S3 – object storage

## Overall Recommendation

There is no single cloud provider that is automatically the best for every organization. The correct choice depends on business requirements, existing technologies, budget, performance requirements, compliance, technical skills, and future growth. AWS is a strong general-purpose choice, Azure is particularly suitable for Microsoft environments, and Google Cloud is particularly strong for AI, data, and Kubernetes workloads.
