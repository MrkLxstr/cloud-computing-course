# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides cloud services for computing, storage, networking, databases, security, analytics, Artificial Intelligence, application development, and other business requirements. Azure is especially useful for organizations that already use Microsoft technologies.

## Global Infrastructure

Azure provides more than 70 regions globally and has more than 400 datacenters. Azure regions are organized into geographies that can provide data residency and compliance boundaries. Many Azure regions also provide Availability Zones for improved resilience and fault isolation.

## Cloud Management Console

The Azure Portal is a web-based unified console used to create, manage, monitor, and configure Azure resources. Users can manage services such as virtual machines, databases, applications, networking resources, and other cloud services through a graphical interface.

## Four Core Services

| Category   | Azure Service          | Description                                                               |
| ---------- | ---------------------- | ------------------------------------------------------------------------- |
| Compute    | Azure Virtual Machines | Provides virtual machines for running applications and operating systems. |
| Storage    | Azure Blob Storage     | Provides scalable object storage for unstructured data.                   |
| Networking | Azure Virtual Network  | Provides private networking for Azure resources.                          |
| Identity   | Microsoft Entra ID     | Provides identity and access management for users and applications.       |

## Three Advantages

1. **Strong Microsoft integration** – Azure works closely with Microsoft's ecosystem, including Windows Server, Microsoft 365, and Microsoft Entra ID.
2. **Large global infrastructure** – Azure has more than 70 regions and more than 400 datacenters.
3. **Enterprise capabilities** – Azure provides services and management features designed for large organizations and hybrid cloud environments.

## Typical Enterprise Use Cases

Azure can be used for:

* Windows Server migration
* Microsoft 365 integration
* Enterprise application hosting
* Database hosting
* Hybrid cloud environments
* Web applications
* Virtual desktops
* Artificial Intelligence and Machine Learning
* Data analytics
* Enterprise identity management
